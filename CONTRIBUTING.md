# Contributing

Thank you for helping improve Preserve.

## Development

1. Install the stable Rust toolchain for `x86_64-pc-windows-msvc`.
2. Create a focused branch for your change.
3. Run `cargo fmt`, `cargo test`, and `cargo clippy --all-targets -- -D warnings`.
4. Open a pull request describing the user-visible effect and how it was tested.

Keep changes limited to the desktop client. Do not submit game files, proprietary assets, credentials, access tokens, private endpoints, or user data.
